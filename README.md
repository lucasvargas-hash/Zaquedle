Zaquedle

Sobre

É um jogo estilo pokedle, de acertar personagens, imagens.

Por que foi feito

Projeto criado para brincar com o canal e adquirir aprendizado.

Como jogar

Digite um palpite no campo de busca (tem sugestões automáticas enquanto você digita) e clique em "Chutar". A cada tentativa errada, a imagem fica um pouco mais nítida, até acabarem as chances.

- **Personagem**: adivinhe quem é a pessoa pela foto distorcida.
- **Tier list**: adivinhe qual tier list é, a partir da imagem borrada.
- **Clássico**: em breve.

Como rodar localmente

Abra o `index.html` num servidor local (por exemplo, com a extensão "Live Server" do VS Code, ou rodando `python -m http.server` na pasta do projeto).
